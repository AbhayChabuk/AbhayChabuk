## Featured Projects

### 01. Cloud Deployment on AWS

**Problem**

Deploying an application is only one part of running it in the cloud. A reliable deployment also needs to consider traffic distribution, scalability, application availability, and infrastructure costs.

**Solution**

Built a cloud deployment project exploring how to run a containerized application on AWS and support scalable traffic handling.

**Key Implementation**
- Containerized the application using Docker.
- Deployed the application on Amazon EC2.
- Used Nginx and Gunicorn to serve the Flask application.
- Integrated an Application Load Balancer for traffic distribution.
- Configured Auto Scaling to support changes in application demand.
- Focused on cost-conscious infrastructure design.

**Technologies**

`AWS` `EC2` `Docker` `Flask` `Gunicorn` `Nginx` `ALB` `Auto Scaling`

### 03. ResuMate — AI-Powered Placement Assistant

**Problem**

Students preparing for placements often need to evaluate their resumes, understand how well their profiles match job opportunities, and prepare for recruitment processes using separate resources.

**Solution**

Developed an AI-powered placement assistance system that brings resume analysis, job matching, and placement preparation capabilities into one application.

**Key Implementation**
- Developed the application using the MERN stack.
- Integrated large language model capabilities through the Groq API.
- Implemented resume analysis and ATS-oriented optimization features.
- Worked on job-fit assessment to help users evaluate their suitability for opportunities.
- Incorporated placement preparation functionality.

**Technologies**

`MongoDB` `Express.js` `React` `Node.js` `Groq API` `LLMs`
